# Code of Conduct

## Our standard

Be respectful, specific and constructive. Disagreement about architecture, privacy or implementation is welcome; harassment, personal attacks, discrimination, threats and deliberate disruption are not.

This project handles sensitive computer-activity metadata, so contributors must also respect other people's privacy. Never publish another person's credentials, tokens, private paths, history databases, capture dumps or other private data without clear permission.

## Where this applies

This standard applies to issues, pull requests, reviews, discussions and other project spaces associated with `dsh-computer-history`.

## Enforcement

The maintainer may edit or remove abusive or privacy-violating content, close or lock threads, reject contributions, or block participants when necessary to keep the project safe and workable.

For security vulnerabilities, use GitHub Private Vulnerability Reporting rather than a public thread. For a sensitive conduct concern, contact the maintainer privately through the contact options available on the maintainer's GitHub profile instead of posting personal details publicly.
