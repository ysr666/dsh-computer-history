## What Computer History does

Computer History is a local-first **work continuity** plugin for DeepSeek Harness.
It turns bounded metadata about your recent work into evidence-backed Work Episodes,
then helps you open a new DSH session with a native `@ Computer History` reference
and a short, grounded continuation handoff. It is not a screenshot recorder or a
full desktop content archive.

## Highlights

- **Continue-first UI.** Recent Projects, Timeline and work Episode selection;
  exact Session/Episode binding and concise agent handoff, with verification and
  next-step targets prioritized rather than raw history copied into chat.
- **Metadata-only collection.** Mac Accessibility, Windows UIA, Linux AT-SPI,
  optional paired browser (Chromium/Firefox) and VS Code Editor Companions.
  No keystroke log, clipboard contents, source bodies, screenshots or page bodies.
- **Local storage.** SQLite history, configurable retention, deletion, export
  and controlled import. History is not independently encrypted at rest; use
  OS user permissions and disk encryption.
- **Scoped privacy controls.** Capture off until consent, explicit app allow;
  allow selected browser origins or vouched editor workspace roots, or deny an
  entire type. Protected/denied resources override allowed ones.
- **Model privacy.** Deterministic summaries by default; model-summary providers
  are separately gated. Continue to a cloud-configured DSH Agent can transmit
  a bounded workspace/task context to that model. Local-first does not mean
  unconditional network isolation.

## Installed-product verification

- **macOS:** a 52-check installed DSH `0.2.0-rc.2` journey has passed,
  including browser privacy matrix, Editor save/test, Continue native capsule,
  Session/Episode binding, plugin disable/re-enable/uninstall, history preservation
  and cleanup.
- **macOS, Windows and Linux:** the same assembled plugin tarball has passed
  clean-install Host/collector transport and installed-browser-client first-run,
  Settings and History/Privacy checks on hosted CI runners.
- **Windows:** independent Notepad → UIA → Host → SQLite integration verified.
- **Linux:** headless CI reports `permission-required` without an X/AT-SPI
  session; this does not prove real-desktop Linux accessibility behavior.

## Limitations / compatibility

- First Alpha, **no stable compatibility contract** or automatic database
  rollback guarantee; back up the local store before reinstalling/downgrading.
- The packaged macOS collector is ad-hoc code signed for DSH plugin execution,
  not notarized as a standalone Finder-distributed app.
- Real capture requires platform permissions and, in strict workspace mode,
  a paired Editor Companion to vouch for the project root.
- Browser/Editor Companion installation and pairing are separate setup steps.
- Tested against DSH `0.2.0-rc.2`; other DSH versions require separate tests.
